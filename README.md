## Сборка

Требуется Python 3.11 или новее.

```sh
python -m pip install -r requirements.txt
python work/war_build.py
```

Сборка создаёт `index.html` в корне (публикуемая версия), `outputs/index.html` и `outputs/Маршалкины.html`. Все необходимые данные и изображения находятся в репозитории. Интернет и пароль для сборки не нужны. Сайт полностью общедоступен по решению владельца.

## Состав

- `work/war_build.py` — основная сборка; `assemble.py`, `*_build.py`, `story_revision.py` — главы и оформление.
- `work/fullsheet.html`, `living.xlsx`, `data/military.xlsx` — исходные семейные таблицы и военная выгрузка.
- `work/*audit*.json`, `familio-all-pages.json`, `fullPeople.json` — результаты сверки и снимки данных.
- `work/assets-revision/`, изображения, шрифты и лицензии в `work/` — локальные ресурсы.
- `work/*.pdf`, исторические HTML и выписки — исследовательские материалы; сохраняют атрибуцию исходных авторов.
- `work/verify-open.cjs` — актуальная браузерная проверка; остальные проверки и одноразовые скрипты отражают историю разработки и не все применимы к текущей открытой версии.

## Проверка

```sh
npm install
npm test
```

Браузерная проверка использует установленный Google Chrome. Для проверки опубликованной версии задайте переменную `ATLAS_URL`.

## Публикация

После сборки закоммитьте изменения и отправьте в основную ветку. Существующий GitHub Actions публикует сайт. Пароли, токены, настройки авторизации, локальные зашифрованные резервные копии и производные HTML-снимки в исходный проект не включены. Исторические скрипты могут ссылаться на такие исключённые снимки и не нужны для актуальной сборки.

Материалы Familio и семейные свидетельства не равнозначны независимо проверенным архивным документам; разночтения сохранены в интерфейсе. Неоднозначные даты не заменяются автоматически в статистике.
