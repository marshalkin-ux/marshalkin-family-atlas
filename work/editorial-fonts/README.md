# Editorial typefaces

Onest Variable (100–900), Prata Regular (400). Both include all Russian uppercase/lowercase letters including Ё/ё; checked directly in TTF cmap tables. Source files and OFL licenses fetched from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/onest
- https://github.com/google/fonts/tree/main/ofl/prata

`../editorial-fonts.css` embeds the complete TTF files as data URIs for offline standalone HTML. Onest supports variable weights 100–900. Prata is regular only; avoid synthetic bold and italic for quoted text. Suggested use: Onest 600–750 for large headings; Onest 400–450 for body; Prata 400 for short literary quotes or occasional display accents.
